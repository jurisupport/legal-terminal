# legal-terminal v0.1.23 쓰레드 초안

기준 기간: 2026년 6월 1일 ~ 2026년 6월 2일  
최신 릴리즈: https://github.com/jurisupport/legal-terminal/releases/tag/v0.1.23

## 복사용 본문

1/
legal-terminal을 v0.1.23까지 올렸습니다.

이번 이틀간의 핵심은 하나입니다. 사무실 서버나 원격 Mac에 있는 사건 폴더를 노트북에서 로컬처럼 열고, Claude Code와 기록뷰어, Markdown 서면 편집기를 한 화면에서 끊기지 않게 쓰는 것.

2/
가장 큰 변화는 원격(SSH) 작업입니다.

SSH 프로필을 저장해 두고, 원격 작성서류/소송기록 루트를 앱에서 직접 찾아 고를 수 있습니다. 원격 사건 폴더를 열면 그 폴더에서 Claude Code가 실행되고, 파일 패널도 SFTP로 원격 파일을 직접 읽고 씁니다.

3/
원격 파일 패널도 많이 넓어졌습니다.

탐색기, PDF/이미지/HWP/CSV 뷰어, Markdown 편집기, 기록뷰어가 `ssh://` 경로를 다룹니다. 새 파일/폴더 생성, 이동, 삭제, 로컬 파일 붙여넣기, 원격 파일/폴더 다운로드까지 같은 흐름으로 묶었습니다.

4/
원격 폴더 선택도 훨씬 덜 답답하게 바꿨습니다.

홈, 루트, OneDrive, iCloud Drive 같은 시작점을 빠르게 누를 수 있고, breadcrumb로 상위 폴더를 오가며, 정렬과 직접 경로 입력으로 사건 폴더를 찾을 수 있습니다.

5/
원격 OneDrive도 보강했습니다.

원격 Mac의 OneDrive 파일이 클라우드 전용 상태이면 rclone으로 먼저 실체화합니다. 사건기록 PDF는 목록을 만들 때 미리 순차 다운로드해서, 나중에 열 때 클라우드 지연을 줄였습니다.

6/
rclone 쪽도 실전 오류를 줄였습니다.

Homebrew 경로의 rclone을 비대화형 SSH 환경에서도 찾고, macOS OneDrive의 조합형 한글 경로를 클라우드 경로에 맞게 정규화합니다. 동기화는 삭제 전파 없이 `copy --update` 중심으로 안전하게 갑니다.

7/
원격 Claude 세션 복원도 들어갔습니다.

원격 `~/.claude/projects` transcript를 읽어 과거 세션을 찾고, `claude --resume`으로 이어서 엽니다. 터미널 탭을 닫거나 작업환경을 복원한 뒤에도 원격 cwd와 SSH 정보를 유지하도록 고쳤습니다.

8/
작업환경 저장/복원도 크게 바뀌었습니다.

문서 탭, 터미널 탭, 좌우 패널 배치, 현재 사건, PDF 보기 설정을 저장합니다. 여러 사건/문서 작업환경은 서로 덮어쓰지 않고 ID별로 저장되고, 복원할 때 목록에서 선택할 수 있습니다.

9/
화면 배치도 더 작업실처럼 만들었습니다.

문서는 왼쪽, 터미널은 오른쪽에 기본으로 열리지만 필요하면 서로 반대편으로 옮길 수 있습니다. 탭 재정렬, 창 간 이동, 새 창 찢어내기도 지원해서 기록·서면·Claude를 상황에 맞게 배치할 수 있습니다.

10/
전자소송기록/PDF 쪽도 다듬었습니다.

전자소송기록 파일명을 문서, 서증, 첨부서류로 더 안정적으로 분류하고, 한글 제목 정규화도 보강했습니다. 암호 PDF, 확대 상태 손 도구, 원격/OneDrive 로딩 안내도 개선했습니다.

11/
Markdown 서면 편집기는 실무 쪽으로 더 붙였습니다.

읽기 좋은 Markdown 본문을 JuriSupport 법률문서 MCP 초안 작성에 넘길 수 있고, 라이브 프리뷰, 표 편집, PDF 내보내기의 텍스트 보존과 레이아웃 안정성을 보강했습니다.

12/
터미널 품질도 계속 손봤습니다.

붙여넣기 줄바꿈 정규화, Cmd/Ctrl+W 닫기, 작업 중/완료/질문 대기 상태 표시, 완료 알림음, 질문 대기 팝업, Mac/Windows IME 조합 위치, 좁은 패널 가독성을 개선했습니다.

13/
설정과 검색도 늘었습니다.

파일트리, 터미널, 문서 검색을 넣고, 알림음/볼륨, 터미널 폰트, Markdown 폰트와 크기 설정을 추가했습니다. 사건 대시보드에서는 원격 열기, 폴더 자동 매칭, 최근 원격 사건 기억도 이어집니다.

14/
배포도 안정화했습니다.

macOS arm64/x64, Windows x64 릴리즈 빌드를 GitHub Actions로 자동화했고, Windows `node-pty` 네이티브 바이너리 검증/포함, 레거시 제거기 실패 복구 설치, macOS Gatekeeper 안내를 정리했습니다.

15/
정리하면 이번 업데이트는 "AI 터미널 앱"이라기보다 "송무 작업환경"에 가까워지는 작업이었습니다.

사건 폴더를 열고, 기록을 보고, 서면을 쓰고, Claude에게 물어보고, 다음 날 같은 작업환경을 다시 여는 흐름까지 하나로 묶었습니다.

16/
다운로드는 최신 릴리즈에서 받을 수 있습니다.

Windows 설치본, Windows 포터블, Mac Apple Silicon DMG/ZIP, Mac Intel ZIP을 올려두었습니다.

https://github.com/jurisupport/legal-terminal/releases/tag/v0.1.23

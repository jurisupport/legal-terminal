# 업무지시 보드

사건을 열고 상단의 **업무 보드**를 누르면 해당 작업 폴더의 보드가 열린다. **일괄 지시**에서 지시를 줄 또는 빈 줄로 구분해 붙여 넣고 각 지시의 담당자, 기한, 검토자와 결재 방식을 선택한다. 에이전트 입력창에 작성한 내용도 **일괄 지시**로 가져올 수 있다. 작업 폴더 선택기에서 다른 사건의 보드로 이동한다.

기본 저장 위치는 사건 작업 폴더의 `_업무지시`다. 지시서와 보고서는 각각 `<id>.md`, `<id>.report.md`에 저장된다. 검토를 사용하면 `<id>.review.md`가 추가된다. 같은 폴더의 `_보고서양식.md`를 편집하면 다음 지시부터 적용된다. `teams.yaml`의 팀 이름, 색상, 에이전트 목록을 바꾸면 조직도가 갱신된다. 담당자 선택 목록은 앱을 실행하는 컴퓨터의 `~/.claude/agents/*.md`에서 읽는다.

**결재함**에서 보고서와 검토 결과, 승인 후 실행할 지시·도구를 확인한다. 외부 작업이 필요하면 원 지시를 등록할 때 ‘승인 후 실행할 지시’와 ‘승인 후 허용할 도구’를 입력한다. 승인하면 그 내용으로 별도 지시가 생성된다. 실행 도중 종료된 외부 작업은 먼저 실제 처리 결과를 확인해야 한다. 일반 업무의 재시작 방식과 동시 실행 수는 보드 설정에서 조정한다.

**일일 보고**는 한국 시간 기준이다. 앱이 실행 중이면 설정 시각 이후 첫 점검에서 `_일일보고/YYYY-MM-DD.md`와 같은 이름의 HTML을 저장한다. 앱이 꺼진 동안 시각이 지났으면 당일 다시 실행할 때 생성한다. HTML은 브라우저에서 파일 하나로 열 수 있다.

## 개발 의뢰의 세 가지 설계 결정

1. **배분기**는 Claude Agent SDK로 지시·검토마다 독립 세션을 만든다. 기존 대화의 대기열과 권한을 상속하지 않는다. 기본 동시 실행 수는 1이다. SSH 사건도 앱의 SDK가 수행하고 파일 작업은 선택한 서버의 사건 폴더를 사용한다.
2. **도구 권한**은 앱이 실제 도구를 호출하는 지점에서 검사한다. 일반 지시는 사건 폴더 조회·문서 읽기·새 초안 작성만 할 수 있다. 외부 MCP 호출은 신뢰하는 HTTPS 서버를 먼저 등록하고 정확한 도구 이름을 결재해야 한다. 작업 폴더에서 실행할 명령을 결재할 때는 `Bash(명령 전문)`을 사용한다. 위험 도구와 명령 패턴은 앱 사용자 데이터의 `work-boards/<보드 식별값>/tool-policy.json`에서 관리한다. 결재 권한은 지시서가 있는 동기화 폴더와 분리해 보관한다.
3. **원격 변경 감지**는 기존 SSH 파일 연결 풀을 재사용한다. 보드별 주기적 목록 조회와 지시 실행 중 발생하는 상태 이벤트를 사용한다. 파일마다 SSH 감시 프로세스를 띄우지 않는다. 동일한 보드를 여러 기기에서 사용할 때에는 처음 배분기를 등록한 기기를 실행 주체로 유지한다. 서로 연결이 끊긴 복제 폴더에서 같은 보드를 동시에 최초 등록하면 파일 동기화 자체가 배타적 실행을 보장할 수 없다.

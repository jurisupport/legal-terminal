# 소송문서 Markdown 서식 규칙 (court-doc-format)

legal-terminal 앱은 md 문서를 한/글 법원서면 표준 서식(HWPX)으로 내보낸다.
변환기는 아래 관례를 인식해 문단 스타일을 정한다. **규칙에서 벗어난 형식은
전부 바탕글로 떨어지므로**, 소송문서 md를 새로 쓰거나 고칠 때는 이 규칙을 그대로 따른다.

## When to use

- 준비서면·소장·답변서·항소이유서·신청서·의견서 등 법원 제출용 md 초안 작성
- 기존 소송문서 md의 구조 수정, HWPX 변환 결과가 이상하다는 문의

## 문서 골격 (이 순서·형식 그대로)

```markdown
# 준비서면

사건	2024나12345 손해배상(기)
원고	김○○
피고	이○○

위 사건에 관하여 피고의 소송대리인은 다음과 같이 변론을 준비합니다.

## 1. 기초 사실

...본문 문단...

### 가. 계약의 체결

...본문 문단...

## 입증방법

1. 을 제1호증 매매계약서
2. 을 제2호증 내용증명

## 첨부서류

- 위 입증방법 각 1통
- 소송위임장 1통

2026. 7. 11.

피고 소송대리인 법무법인 ○○
담당변호사 홍길동

서울중앙지방법원 제3민사부 귀중
```

## 규칙 상세

### 1. 제목
- 첫 줄에 번호 없는 `# 제목` 하나. 예: `# 준비서면`, `# 소장`
- 자간(글자 사이 공백)은 변환기가 자동으로 넣으므로 **붙여 쓴다** ("준 비 서 면" 금지).

### 2. 사건표시 캡션 (본문 스타일로 변환됨)
- `라벨` + **탭 문자 1개** + `값`. 공백으로 벌리지 않는다.
- 인식되는 라벨: 사건, 당사자, 원고, 피고, 피고인, 신청인, 피신청인, 채권자,
  채무자, 항소인, 피항소인, 상고인, 피상고인, 피의자, 피해자, 고소인, 변호인,
  수신, 참조, 제목
- 캡션 줄들은 **빈 줄 없이 연달아** 쓴다 → 한 문단(쉬프트엔터 줄바꿈)으로 합쳐진다.
- 굵게(`**`)·코드블록·표로 감싸지 않는다.

### 3. 개요 제목 (개요 1~6수준으로 변환됨)
- 마크다운 헤딩에 **번호를 직접 붙인다**(자동 번호 아님): `## 1. 청구원인`, `### 가. 사실관계`
- 번호 형식이 수준을 정한다: `1.`→1수준, `가.`→2수준, `1)`→3수준, `가)`→4수준, `(1)`→5수준, `(가)`→6수준

### 4. 구분 표제 (가운데 14pt 굵게 자동)
- 단독 줄로 쓰면 자동 인식: 다음, 아래, 첨부서류, 첨부자료, 입증방법, 증거방법,
  소명방법, 증거자료, 신청취지, 신청이유, 청구취지, 청구원인
- 자간·가운데 정렬을 직접 넣지 않는다 (자동 처리).

### 5. 목록 (입증방법·첨부서류 항목)
- `- 항목` 또는 `1. 항목` 목록으로 쓴다 → 한 문단 안에서 줄바꿈으로 이어진 사건표시 서식이 된다.

### 6. 날짜·서명 블록 (탭 밀기 서명 블록으로 변환됨)
- 날짜는 `2026. 7. 11.` 형식 **단독 줄**.
- 바로 다음 줄(들)에 지위·대리인: `피고 소송대리인 법무법인 ○○`, `담당변호사 홍길동`
- 오른쪽 정렬 주석·탭을 직접 넣지 않는다. "변호사 홍길동"의 이름 자간도 자동.

### 7. 수신 법원
- 마지막 줄에 `…법원 … 귀중` 단독 줄. "귀중"으로 끝나야 인식된다.

### 8. 정렬·표 (필요할 때만)
- 블록 정렬: `<!-- lt-align:center -->` … `<!-- /lt-align -->` (right도 가능)
- 표는 GFM 표. 열 너비는 표 바로 아래 `<!-- colw: 3cm,, -->`,
  셀 정렬은 `<!-- cellalign: 1:2=c -->` (행:열=l/c/r)

## 하지 말 것

- 캡션 라벨과 값 사이를 공백 1칸으로 구분 (탭 1개가 표준, 공백은 2칸 이상만 인식)
- 제목·표제에 수동 자간
- 헤딩 없이 굵은 글씨(`**1. 청구원인**`)로 개요 흉내
- 날짜·서명·귀중 줄을 한 문단에 뭉치거나 목록으로 작성
- HTML 태그 사용 (lt-align/colw/cellalign 주석 외 주석도 불인식)
